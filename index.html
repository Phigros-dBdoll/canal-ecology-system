基于Google Earth Engine与WebGIS的RSEI生态评价平台

研究背景：
京杭大运河是重要的线性文化遗产与生态廊道。本系统面向京杭大运河沧州段生态修复工程，结合遥感生态指数与WebGIS交互查询，实现2000—2025年生态环境变化的时空分析与可视化展示。

核心关键词：
RSEI生态评价、NDVI植被指数、WET湿度指数、NDBSI裸地/建设指数、LST地表温度、GEE遥感处理、WebGIS可视化、缓冲区分析、生态修复成效评价。
Project Overview (EN)
This is a Web GIS system for spatiotemporal analysis of canal ecology from 2000 to 2025.
It integrates RSEI, NDVI, WET, NDBSI, and LST indicators with buffer zone analysis.
Users can explore ecological changes by year and buffer zones (100m / 300m / 1000m).
The system demonstrates remote sensing data processing, ecological assessment, and interactive Web GIS visualization.
数据说明：
① 时序统计数据（CSV）：2000—2025年 NDVI、WET、NDBSI、LST、RSEI 指标统计结果。
② 空间缓冲区（GeoJSON）：京杭大运河沧州段 100m、300m、1000m 缓冲区范围。
