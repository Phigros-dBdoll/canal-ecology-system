# Canal Ecology Web GIS System

A Web GIS demo for spatiotemporal ecological analysis of the Cangzhou section of the Grand Canal, China.

## Features
- RSEI-based ecological evaluation
- NDVI, WET, NDBSI and LST visualization
- Buffer zone analysis (100m, 300m, 1000m)
- Interactive Leaflet map and ECharts charts
- Static deployment with GitHub Pages

## Demo
https://Phigros-dBdoll.github.io/canal-ecology-system/

## Data
- Landsat-based indicators (2000–2025)
- RSEI, NDVI, WET, NDBSI, LST
- Buffer zones: 100m / 300m / 1000m

## Tech Stack
- JavaScript
- Leaflet
- ECharts
- PapaParse
- GeoJSON

## Description
This project demonstrates how remote sensing data and GIS techniques can be integrated into an interactive web-based visualization system for ecological analysis.
